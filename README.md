# Geist
Generate Papers as fully humanized essays. 

### Stack
Monorepo
Built with React front end, Spring Boot backend

### How am I utilizing AI?
As of now writing code by hand, UI is AI-Assisted. 
This may seem wrong considering the state of SWE rn, but I use AI heavily in my day to day work and 
want to make sure I can still design a backend, build endpoints, handle requests, write auth, 
build a rate limiting system, make design decisions, etc by hand and not rely fully on AI.
